# 컷넘버 (CutNumber)

[日本語](ja.md) · [English](../../README.md) · **한국어** · [简体中文](zh-Hans.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Português](pt.md) · [Русский](ru.md) · [العربية](ar.md)

컷넘버는 이미지의 순서를 정하고 연속 번호로 파일을 저장하는 무료 데스크톱 앱입니다. After Effects에 가져올 이미지 시퀀스를 만들거나, 무음 H.264 MP4를 내보낼 수 있습니다.

[YouTube에서 32초 시연 보기][demo] · [최신 릴리스][latest]

## 다운로드

- [macOS DMG][mac] (Apple Silicon, macOS 13 이상). DMG를 열고 **CutNumber.app**을 **응용 프로그램** 폴더에 옮긴 뒤 실행하세요. 이 앱은 Ad Hoc 서명되었으며 Apple 공증을 받지 않았습니다.
- [Windows ZIP][win] (x64, Windows 11 또는 Windows 10 22H2). 압축을 모두 풀고 **CutNumber.exe**를 실행하세요. 바로 가기를 만들려면 **Install.cmd**를 실행하세요. 필요한 .NET 런타임이 포함되어 있습니다.

## 사용 방법

1. 도구 막대, 드래그 앤 드롭, 붙여넣기로 이미지나 폴더를 추가하세요.
2. 생성 또는 수정 시간으로 정렬하거나 목록에서 행을 이동하세요. 이미지를 선택하면 오른쪽에 미리보기가 표시됩니다.
3. 번호를 붙인 복사본을 저장하거나 원본 파일명을 바꾸세요. 동영상이 필요하면 프레임 속도를 선택하고 MP4로 내보내세요.

기본 언어는 영어입니다. 상단의 **Language**에서 **한국어**를 선택하면 즉시 적용되고 다음 실행에도 유지됩니다.
