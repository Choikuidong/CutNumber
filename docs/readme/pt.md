# CutNumber

[日本語](ja.md) · [English](../../README.md) · [한국어](ko.md) · [简体中文](zh-Hans.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · **Português** · [Русский](ru.md) · [العربية](ar.md)

O CutNumber é um aplicativo de desktop gratuito para organizar imagens, numerar os nomes dos arquivos em sequência e exportar o resultado como vídeo MP4 (H.264) sem áudio. Use-o para preparar sequências de imagens para o After Effects e outros editores.

[Assista à demonstração de 32 segundos no YouTube][demo] · [Versão mais recente][latest]

## Baixar

- [DMG para macOS][mac] (Apple Silicon, macOS 13 ou posterior). Abra o DMG, arraste **CutNumber.app** para **Aplicativos** e abra o aplicativo nessa pasta. O aplicativo tem assinatura ad hoc e não passou pela notarização da Apple.
- [ZIP para Windows][win] (x64, Windows 11 ou Windows 10 22H2). Extraia todo o conteúdo e abra **CutNumber.exe**. Execute **Install.cmd** para criar atalhos. O runtime do .NET está incluído.

## Como usar

1. Adicione imagens ou pastas pela barra de ferramentas, arrastando ou colando.
2. Ordene pela data de criação ou de modificação, ou mova as linhas. Selecione um quadro para ver a prévia.
3. Salve cópias numeradas ou renomeie os arquivos originais. Para criar um vídeo, escolha a taxa de quadros e exporte como MP4.

O idioma inicial é o inglês. Escolha **Português** no seletor **Language**. A interface muda na hora e a preferência fica salva.
