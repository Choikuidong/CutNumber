# CutNumber

[日本語](ja.md) · [English](../../README.md) · [한국어](ko.md) · [简体中文](zh-Hans.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [Português](pt.md) · **Русский** · [العربية](ar.md)

CutNumber — бесплатное приложение для упорядочивания изображений, пакетного переименования с последовательной нумерацией и экспорта в MP4 (H.264) без звука. В нём можно подготовить последовательность кадров для After Effects и других видеоредакторов.

[Посмотреть 32-секундную демонстрацию на YouTube][demo] · [Последняя версия][latest]

## Скачать

- [DMG для macOS][mac] (Apple Silicon, macOS 13 или новее). Откройте DMG, перетащите **CutNumber.app** в папку «Программы» и запустите приложение оттуда. Приложение подписано подписью ad hoc и не прошло нотарификацию Apple.
- [ZIP для Windows][win] (x64, Windows 11 или Windows 10 22H2). Полностью распакуйте ZIP и запустите **CutNumber.exe**. Для создания ярлыков запустите **Install.cmd**. Среда выполнения .NET включена.

## Как пользоваться

1. Добавьте изображения или папки с помощью панели инструментов, перетаскивания или вставки.
2. Отсортируйте кадры по времени создания или изменения либо переместите строки вручную. Выберите кадр для просмотра.
3. Сохраните копии с последовательными номерами или переименуйте исходные файлы. Чтобы создать видео, выберите частоту кадров и экспортируйте в MP4.

Язык интерфейса по умолчанию — английский. Выберите **Русский** в меню **Language**. Интерфейс переключится сразу и запомнит ваш выбор.
